# Washington Township Fire Department Employee Portal - Version 9

Version 9 is the final polish pass before testing.

## Changes
- Slightly reduced header height.
- Moved search into its own full-width row directly beneath navigation.
- Increased Department System card size and visual hierarchy.
- Increased primary icons and card titles.
- Changed system action text from "Launch" to "Open".
- Increased resource-row height for touch-friendly use.
- Added subtle hover motion and accent treatment to resource rows.
- Kept the muted Administration button.
- Preserved the crew-facing vs administrative separation.
- Volunteer Dashboard remains removed.
- Incident Command remains excluded from general portals.
- CPR registration remains excluded because it is public-facing.

## Testing goal
Version 9 should now be treated as the testing baseline before any further feature changes.

## Deployment
Upload this ZIP directly to the existing Cloudflare Pages project.
